## 1. 最优配置 C_*

### 1.1 几何描述（D₃ 对称）

`R(x,y) = ( -(x+√3 y)/2, (√3 x − y)/2 )` 是逆时针 `2π/3` 旋转。12 个圆心为

```
c_{3j+k+1} = R^k( u c,  u s )        j=0, k=0,1,2
c_{3j+k+4} = R^k( u c, −u s )        j=1, k=0,1,2
c_{3j+k+7} = R^k( −v, 0 )            j=2, k=0,1,2
c_{3j+k+10}= R^k(  w, 0 )            j=3, k=0,1,2
```

即有序 12 元组

```
C_* = ( (uc,us), R(uc,us), R²(uc,us),
        (uc,−us), R(uc,−us), R²(uc,−us),
        (−v,0),  R(−v,0),  R²(−v,0),
        (w,0),   R(w,0),   R²(w,0) )          （c = cos h, s = sin h）
```

- 前 9 个（半径 `u` 的 6 个 + 半径 `v` 的 3 个）是"边界圆盘"，第 10–12 个
  （半径 `w`）是内部圆盘；
- 9 个圆周锚点（覆盖弧的端点）为
  `(1,0)`、`(c²−s², 2cs)` 及其关于 `π/3` 轴的反射，再作 `R, R²`，

## 2. `P(α) = 0` 的证明（消元证书链）

`P` 由精确消元得到，链条中每一步都有机器可检验的恒等式
（脚本 `verify/minpoly_zero_cert.py`，输出 `verify/out/minpoly_zero_certificate.json`，
全部检查 `PASS`）。

设 `g3, g5, f2, f4` 为 (E3),(E5),(E2),(E4) 左端，`F6 = det(2M)`（整系数），
`Pc = c²−s²+2zcs`，`A1 = 2r + (u²−r²−r) − Pc`，`A0 = (u²−r²−r)(u²−r²−r+r) − 1 + r²`。

| 步骤 | 内容 | 检验方式 |
|---|---|---|
| L1 | `g3 − g5 = A1 v − A0`（模 `f4`）；`A1² g3 − E3` 被 `A1 v − A0` 整除 ⟹ `E3 ∈ ⟨g3,g5⟩` | 精确多项式除法 |
| L2 | `A1^k F6 − DET` 被 `A1 v − A0` 整除（`k = deg_v F6`）⟹ `DET ∈ ⟨g3,g5,F6⟩` | 精确多项式除法 |
| L3 | `R3 = rem_u(E3)`，`R6 = rem_u(DET)` 模 `f2` | 精确余式 |
| L4 | `a_i² f2 − γ_i` 被 `a_i u + b_i` 整除（`i=1,2`）⟹ `γ_i ∈ ⟨f2,R3/R6⟩` | 精确多项式除法 |
| L5 | `γ_i^red = A_ic + B_ic s`（模 `s²+c²−1`）；`R1 = B2c γ1 − B1c γ2`；`R2 = A1c² − B1c²(1−c²)`（模 `z²−3`） | 精确恒等式 |
| L6 | `α1 ≡ 0`，`β2 ≡ 0`（`R1 = β1 z`，`R2 = α2`）；`S2 := −3β1² = (β1z)² − β1²(z²−3) ∈ I`；`V := α2² ∈ I` | 精确恒等式 |
| L7 | `S2 = κ (r+1)⁴ r¹⁶ c² (c²r²+c²−1)² F²`，`V = κ′ (r+1)⁴ r⁸ G²` | 精确因式分解 |
| L8 | 上述余因子在根盒上非零（区间算术）⟹ `F(c_*,r_*) = 0`，`G(c_*,r_*) = 0` | 有理区间 |
| L9 | `E(r) := Res_c(F,G)`（`deg E = 444`），`lc_c(F)(r_*) ≠ 0`，`lc_c(G)(r_*) ≠ 0` ⟹ `E(r_*) = 0` | 有理区间 |
| L10 | `E` 的 9 个不可约因式中，只有 37 次因式在 `r` 盒上可取零 ⟹ `P(r_*) = 0` | 有理区间 |

因式次数分布：`E = const · ∏ f_i^{m_i}`，`deg f_i = (1,1,1,2,5,6,18,37,65)`。
在 `r` 盒上，除 37 次因式外所有因式的取值区间都不含 0（例如 `r` 因式区间
`[0.361103, 0.361103]`、65 次因式 `[47072.5, 47072.5]`）。

由 L1–L10：`P(r_*) = 0`。又 `P` 不可约，故 `P` 是 `r_*` 的**极小多项式**，
`[Q(r_*):Q] = 37`。

**独立旁证（整数关系，非证明）**：用 1000 位 `r_*` 直接计算得 `P(r_*) = 1.34e-991`。

mpmath 的 `pslq` **不能**用于本问题的复核：诊断脚本 `tools/pslq_capability.py`
对"已知的" d=4、系数 ~1e17 的关系在所有 `maxcoeff` 设置下都返回"无关系"
（0 秒内退出），说明该实现对系数 ~1e6 以上失效；同一实现对 `√2+√3`（系数很小）正常。

改用**精确 LLL** 复核（`tools/lll_relation.py` → `runtime/lll_relation.log`）：
在整关系格 `(e_i, round(N ρ^i))`（`ρ = 2r_*`，`N = 10^700`）上做 LLL，
再对约化基的每一行**直接高精度求和** `Σ b_i ρ^i`：

```
d = 37: 最小的 |Σ b_i ρ^i| = 9.15254e-888   (max|b| = 4.61e14)   ← 真关系
         次小              = 1.71793e-683                      ← 仅由取整噪声导致
         把 Σ b_k ρ^k 换回 r 的多项式：次数 37，且 余式 mod P = 0
```

即在**完全不同的算法**（LLL 整数关系）下独立恢复了同一个 37 次多项式，
且它恰是 `P` 的整数倍。这确认了消元链没有代数差错。

**极小性不依赖该复核**：`P` 不可约且 `P(r_*) = 0` 已足以推出 `P` 是极小多项式；
`P(r_*) = 0` 本身由 §2 的精确证书链给出。

## 3. 覆盖性证明 `D ⊆ ⋃ B(c_i, α)`

本文给出**独立于外部参考实现**的覆盖证明，思路是"三角剖分 + 五个初等引理"，
把连续覆盖归约为有限个精确不等式检查。脚本 `verify/coverage_cert.py`，
输出 `verify/out/coverage_certificate.json`（全部 `PASS`）。

### 3.1 五个初等引理

1. **三角形引理**：外接圆半径 ≤ r 的三角形被以其三顶点为心的三个 r-圆盘覆盖。
   （证：把外心平移到原点，`x = Σλ_i a_i` 时 `Σλ_i‖x−a_i‖² = R² − ‖x‖² ≤ R²`。）
2. **凸性**：圆盘凸，故三个顶点都在 `B(c,r)` 内的三角形也在 `B(c,r)` 内。
3. **双圆切换引理**：若 `q ∈ B(a,r) ∩ B(b,r)`，则 `conv{a,b,q} ⊆ B(a,r) ∪ B(b,r)`。
4. **圆弧引理**：若 `B(c,r)` 含一段圆周弧的两个端点，且 `c` 的方向严格位于两端点
   角度之间，则该弧整段含于 `B(c,r)`（沿弧的距离平方
   `f(θ) = ρ²+1−2ρcos(θ−φ)` 在 `θ=φ` 取唯一极小，故弧上最大值在端点取到），
   由凸性进一步得到"弧 + 弦"围成的弓形也在盘内。
5. **PL 分片线性圆盘**：见 3.3。

### 3.2 三角剖分

顶点 21 个：12 个圆心 `C_0..C_11` + 9 个锚点 `Q_0..Q_8`（角度
`198.22°, 240°, 281.78°, 318.22°, 0°, 41.78°, 78.22°, 120°, 161.78°`）。

31 个面：

- **核心 13 面**（顶点全为圆心）：
  `(0,1,11),(0,10,8),(0,11,10),(1,2,11),(2,3,11),(3,4,9),(3,9,11),(4,5,9),(5,6,9),(6,7,10),(6,10,9),(7,8,10),(9,10,11)`
- **A 型 9 面** `(Q_{i−1}, Q_i, C_i)`，`i = 0..8` —— 由引理 2 被 `B(C_i, α)` 覆盖；
- **B 型 9 面** `(Q_i, C_i, C_{i+1})` —— 由引理 3 被 `B(C_i,α) ∪ B(C_{i+1},α)` 覆盖
  （因 `Q_i ∈ B(C_i,α) ∩ B(C_{i+1},α)`）。

再补上 9 个圆周弓形（锚点之间的弧与弦之间），由引理 4 被 `B(C_i, α)` 覆盖。
于是 `D = ` 九边形 `∪` 9 个弓形 `⊆ ⋃_{i=1}^{12} B(c_i, α)`。

### 5.3 Lean 形式化（`lean/Covering.lean`）

用 Lean 4 + Mathlib 证明了覆盖证明所依赖的核心几何引理（对任意实内积空间）：

```lean
theorem sum_weighted_dist_sq {n : ℕ} (a : Fin n → E) (c x : E) (R : ℝ)
    (hR : ∀ i, ‖a i - c‖ = R) (lam : Fin n → ℝ) (hsum : ∑ i, lam i = 1)
    (hx : x = ∑ i, lam i • a i) :
    ∑ i, lam i * ‖x - a i‖ ^ 2 = R ^ 2 - ‖x - c‖ ^ 2

theorem triangle_covering {n : ℕ} (a : Fin n → E) (c x : E) (R : ℝ)
    (hR : ∀ i, ‖a i - c‖ = R) (lam : Fin n → ℝ) (hlam : ∀ i, 0 ≤ lam i)
    (hsum : ∑ i, lam i = 1) (hx : x = ∑ i, lam i • a i) (hne : ∃ i, 0 < lam i) :
    ∃ i, ‖x - a i‖ ≤ R
```

即 `docs/RESULT.md` §3.1 的**引理 T**：外接圆半径 ≤ R 的三角形被以其三顶点为心的
三个 R-圆盘覆盖。文件编译**零错误零警告**（无 `sorry`）。

尚未形式化：引理 C/S/A（凸性、双圆切换、圆弧）与全部区间算术证书。
